# 重庆市育肥猪养殖收入保险赔款测算

这是一个可独立运行、适合放入 GitHub Pages 子目录的静态网页工具。第一版只测算“育肥猪养殖收入责任”，不收集客户姓名、身份证、手机号、银行账号和详细家庭住址。

## 已实现功能

- 保单起止期、承保数量、此前已纳入数量录入与校验；
- 目标价格自动读取和手动录入两种模式；
- 同一保单的所有销售期固定使用特别约定月份的同一个目标价格；
- 新增、复制、清空、删除多个约定销售期；
- 销售期可跨周、跨月、跨年，也可以不是完整自然月；
- 按起止日期包含的每个自然日计算实际价格；
- 六档累进赔付、120公斤计算重量、每头600元封顶；
- 每头赔款保留完整精度，乘数量后销售期总赔款保留两位小数；
- 数量、保险期间、前30天限制、销售期重叠、价格缺失和责任限额校验；
- 多销售期明细、汇总、完整计算过程、来源链接；
- A4打印和浏览器导出PDF。

## 本地运行

不要直接双击 `index.html`，因为浏览器通常会阻止本地 HTML 读取 JSON。进入本文件夹后任选一种简单方式启动静态服务器：

```bash
python -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000/
```

Windows 如果 `python` 命令不可用，可尝试：

```bash
py -m http.server 8000
```

## 目标价格维护

公共目标价格保存在 `data/target-prices.json`。目前仅预置已经确认的 `2026年8月 12.84元/公斤`，未虚构其他月份。正式公告链接和公告日期尚未录入时，页面会如实显示数据状态。

支公司专员在网页中手动输入的目标价格只存在于当前页面，不会写回该 JSON，也不会覆盖公共数据。

## 重要口径说明

正式方案原文写有“每个约定销售期为1个月”。本工具按项目中已经再次确认的操作口径实现：不强制销售期恰好为一个月，专员填写什么起止日期，就按该日期范围内每个自然日计算，开始日和结束日均计入。

本工具只用于业务测算和过程复核，正式理赔结论仍以保险合同、特别约定、行业协会正式公告、农委正式数据及理赔审核资料为准。
