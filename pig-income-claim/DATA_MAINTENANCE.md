# 价格数据维护说明

## 一、目标价格

文件：`data/target-prices.json`

每个月新增一条记录，不要覆盖历史月份。至少填写：

```json
{
  "month": "2026-09",
  "display_month": "2026年9月",
  "target_price": 12.34,
  "display_precision": 2,
  "unit": "元/公斤",
  "announcement_date": "2026-09-02",
  "announcement_title": "正式公告标题",
  "source_url": "正式公告链接",
  "source_name": "重庆市保险行业协会",
  "status": "正式公告已核验",
  "note": "按公告显示精度使用"
}
```

`target_price`必须使用行业协会正式公告显示的价格精度，不得写入测算底层未正式发布的更多小数。

## 二、农委周报数据

文件：`data/pig-weekly-prices.json`

每条记录保留年度、周次、监测周期、价格、发布日期、来源链接、抓取时间和状态。不得用上一周价格、均值或推算值补齐缺失周。

当前基线：

- 最新核验周次：2026年第31期；
- 监测周期：2026-07-27至2026-08-02；
- 待宰活猪收购均价：11.64元/公斤；
- 发布日期：2026-08-04；
- 来源：重庆市农业农村委员会。

## 三、自动检查脚本

```bash
python scripts/fetch_pig_weekly_prices.py
```

脚本支持旧版正文价格和新版图片价格。新版图片必须同时满足：

1. OCR唯一识别到“待宰活猪”行中的合理价格；
2. OCR置信度达到阈值；
3. 能用上期价格和正文环比变化交叉验证到相同的两位小数。

任一条件不满足时，脚本不会写入该期数据，只在日志中说明失败原因。

如需针对某个已知公告测试：

```bash
python scripts/fetch_pig_weekly_prices.py --article-url "公告链接" --dry-run
```

## 四、每日价格映射

```bash
python scripts/build_daily_prices.py --year 2026
```

映射规则：周报价格覆盖监测周全部自然日，周一到周日均使用该周价格；跨月和跨年按真实日期写入。未发布日期保持 `price: null` 和 `status: 待更新`。

## 五、人工复核建议

自动工作流更新后，建议专人检查：

- 周次和监测周期是否对应；
- 待宰活猪收购均价是否与官网图片一致；
- 来源链接是否能打开；
- 每日 JSON 是否恰好映射7天（跨年周在单一年度文件中可能少于7天）；
- 新增数据没有覆盖或修改历史已核验记录。
