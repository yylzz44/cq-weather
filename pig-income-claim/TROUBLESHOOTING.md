# 常见错误排查

## 页面提示“本地价格数据读取失败”

原因通常是直接双击打开了 `index.html`。请用 `python -m http.server 8000` 启动本地静态服务器，再访问 `http://localhost:8000/`。

## 选择月份后没有目标价格

检查 `data/target-prices.json` 是否包含该月份。未正式确认的月份不要自行编造；可临时切换“手动录入”，并在测算结果中保留复核提示。

## 销售期显示缺失日期

说明 `data/pig-daily-prices.json` 中对应自然日没有价格。不得用上一期或均价补齐。等待周报发布并更新数据后重新测算。

## 自动更新没有发现新周报

先查看工作流日志：

- 如果提示列表页读取失败，可能是农委网站临时不可用或页面路径改变；
- 如果提示未安装Tesseract，检查“安装中文OCR”步骤；
- 如果提示OCR多个候选或环比校验失败，必须人工核对当期官网图片，不要降低校验标准后直接写入；
- 如果提示没有变化，可能当期周报尚未发布或已经存在。

## GitHub Actions运行后不能提交

在仓库 Settings → Actions → General 中检查 Workflow permissions，确保工作流允许写入仓库内容。若分支受保护，还需要按仓库规则调整自动提交方式。

## 部署后出现404

确认：

1. 文件夹名称确实是 `pig-income-claim`；
2. 文件夹中直接存在 `index.html`；
3. 上传位置是 GitHub Pages 实际发布根目录；
4. 访问地址末尾包含 `/pig-income-claim/`；
5. 主站自定义域名 `www.ciccq.cn` 仍正确指向该 Pages 站点。

## 打印内容被浏览器页眉页脚遮挡

在浏览器打印窗口中关闭“页眉和页脚”，纸张选择A4，缩放选择默认或“适合页面”。
